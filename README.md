# 아로시 AI 전화 상담봇 (프로토타입 v1.0)

화장품 브랜드 아로시 고객센터 전화를 AI 에이전트가 받는 프로토타입이다.
배송 조회, 주문 취소, 반품·환불, 행사·사은품 문의를 상담원 없이 처리하고, 직접 해결할 수 없는 일만 상담원에게 넘긴다.
PC 브라우저에서 화면 키패드와 마이크(또는 글자 입력)로 통화를 흉내 낸다.

- 주문·행사 데이터는 전부 지어낸 더미다. 주문은 10건, 행사는 3건이 있다.
- 취소·반품 같은 접수는 실제 시스템에 반영되지 않고 기록 파일에만 남는다.
- 실제 전화 연결은 들어 있지 않다.

## v1.0에 들어 있는 것

- 텍스트 채팅과 음성(STT·TTS) 통화 데모 화면
- 끊지 않고 이어서 말하는 연속 음성 대화
- 코드로 막은 안전장치: 키패드로 확인된 주문만 조회, 출고된 주문은 취소 접수 불가, 고객 확인 없이는 접수 불가, 툴 결과에 없는 날짜는 답변에서 걸러냄
- 평가 세트와 안전선 테스트

## 1. 실행 방법

Windows 11, Python 3.11 기준이다. 명령은 이 폴더에서 PowerShell로 실행한다.

**1) 설치 (처음 한 번)**

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

**2) 키 넣기 (처음 한 번)**

```powershell
Copy-Item .env.example .env
```

만들어진 `.env` 파일을 열어 `GMS_KEY=` 뒤에 GMS 키를 붙여 넣는다.
이 키 하나로 AI 답변, 음성 인식, 음성 합성을 모두 쓴다. `.env`는 git에 올라가지 않는다.

**3) 서버 켜기**

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.server:app --port 8000
```

브라우저(Chrome 권장)에서 http://localhost:8000 을 연다. 끌 때는 PowerShell 창에서 `Ctrl+C`를 누른다.

키가 제대로 동작하는지만 먼저 보고 싶으면 아래를 실행한다. 크레딧을 조금 쓴다.

```powershell
.\.venv\Scripts\python.exe -m app.check_gms
```

## 2. 화면 사용법

1. 전화기 모양의 **통화 시작** 버튼을 누른다. 봇이 시작 멘트를 한다.
2. **주문 문의:** 키패드로 주문번호 숫자 6개를 누르고 `#`을 누른다. 잘못 눌렀으면 `*`로 지운다.
3. **행사·상품 문의:** 아무것도 누르지 않은 상태에서 `9`를 누른다. 주문번호 없이 물을 수 있다.
4. 그다음부터는 말로 묻는다.
   - **글자로:** "말하기" 칸에 쓰고 Enter를 누른다.
   - **음성으로:** "음성 모드"를 체크한다. 전화처럼 그냥 말하면 되고, 말을 멈추면 봇이 소리로 답한다. 마이크 권한을 허용해야 한다.
5. 다른 통화를 해 보려면 통화를 다시 시작한다.

알아 둘 것이 몇 가지 있다.

- 데모 속 "오늘"은 **2026년 11월 25일 수요일 오후 2시**로 고정되어 있다.
- 주문번호는 반드시 키패드로 입력한다. 말로 불러 주면 봇이 키패드 입력을 부탁한다.
- 같은 말을 해도 봇의 표현은 매번 조금씩 다르다.
- 글자 통화 한 건에 GMS 크레딧이 30~50쯤 든다. 음성 모드는 더 든다.

브라우저 없이 터미널에서 글자로만 해 볼 수도 있다.

```powershell
.\.venv\Scripts\python.exe -m app.cli
```

## 3. 할 수 있는 일

| 분야 | 내용 |
| --- | --- |
| 주문 확인 | 키패드로 받은 주문번호로 주문을 확인한다 |
| 배송 조회 | 배송 상태, 택배사, 송장번호, 도착 예정일을 안내한다. 세트가 나눠 배송될 때는 박스별로 안내한다 |
| 취소 | 출고 전 주문의 취소 요청을 접수한다 |
| 반품·환불 | 받은 상품의 반품 요청을 접수하고, 환불에 걸리는 기간을 안내한다 |
| 파손·불량 | 파손·불량 신고를 접수한다 |
| 행사·사은품 | 행사 기간, 대상, 구매 한도, 사은품을 안내하고, 사은품 누락을 접수한다 |
| 상담원 연결 | 직접 해결할 수 없는 일은 상담원에게 넘긴다 (데모에서는 연결됐다는 표시만 나온다) |

## 4. 폴더 구성

| 위치 | 내용 |
| --- | --- |
| `app/` | 서버, 에이전트, 툴(안전장치), 음성, 키패드, 데모 화면 |
| `data/reference.md` | AI가 참고하는 응대 기준 문서 (환불·출고 기간, 취소·반품 기준, 행사 3건) |
| `data/orders.json` | 더미 주문 10건 |
| `config.toml` | 설정. AI 모델, 음성 모델, 데모 속 "오늘" 날짜 |
| `evals/` | 평가 세트와 채점 실행기 |
| `tests/` | 안전선 테스트 (AI를 부르지 않는다) |

## 5. 테스트와 평가

안전선 테스트는 크레딧을 쓰지 않는다.

```powershell
.\.venv\Scripts\python.exe tests\test_tools.py
```

평가 세트는 실제로 AI를 불러 채점하므로 크레딧을 쓴다. 결과는 `evals/runs/`에 남는다.

```powershell
.\.venv\Scripts\python.exe -m evals.run
```

## 6. 기록

| 위치 | 내용 |
| --- | --- |
| `logs/calls/통화ID.jsonl` | 통화별 입력, AI가 부른 조회·접수와 그 결과, 봇의 말 |
| `logs/requests.jsonl` | 접수 기록 (취소, 반품, 사은품 누락, 파손·불량) |
| `logs/tts_cache/` | 한 번 만든 음성. 같은 문장은 다시 만들지 않고 바로 재생한다 |
